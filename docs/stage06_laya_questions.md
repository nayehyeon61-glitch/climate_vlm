# Stage 06: 예측 뒤에서 Laya가 typed 질문에 답하기

소유자 요청(2026-11-07): Laya를 더 써서 이득을 볼 학습 방법과 위치가 있을까? 세 위치 가운데 "예측 뒤 typed 질문 응답"을
골랐습니다.

가설: 수치 모델이 먼저 예측하고, Laya의 vega 판독기가 그 예측을 요약한 문장을 읽어 정해진 형식의 질문(예/아니오, 3단계,
4지선다)에 답하면, (1) 확률이 보정되고(보정 오차가 작고), (2) 같은 숫자를 직접 쓰는 단순한 기준선보다 정확하거나 적어도
같으며, (3) 자동 응답(route auto)으로 내보낸 답은 검토(review)로 넘긴 답보다 정확하다.

> 상태: 진행 중.

## 왜 이 위치인가

- stage 02에서 Laya를 전문가 라우터로 미세조정하면 다수 클래스로 무너졌습니다. 그래서 여기서는 판독기를 고정하고,
  Laya가 제공하는 `fit()`(고정 특징 위의 작은 head)과 보정(온도, conformal 집합, 자동/검토 경계)만 씁니다.
- stage 03에서 LLM이 직접 문장으로 답하게 하자 형식만 배웠습니다. typed 질문은 답이 선택지라서 채점과 보정이 분명합니다.
- 수치 예측은 stage 04의 이류 갈래(sfno_advect)로, 지금까지 유일하게 persistence를 이긴 모델입니다.

## 설계

- 영역: 동아시아(28–51N, 110–143E), WB2 64×32 격자의 4×6 칸, 사분면 NW/NE/SW/SE.
- 상태 문장: 모델이 발행 시각에 가진 것과 그 예측만 씁니다. 발행 시각 D_μ 상태(T850 영역 평균과 사분면, Z500, 850 hPa
  온도 이류, 지난 24 h 변화)와 +24 h, +72 h 예측 변화(T850 영역 평균과 사분면, Z500)입니다. 예:
  `East Asia 28N-51N 110E-143E, issued 2020-01-05 00 UTC. Now: T850 -6.3 C (NW -12.1, ...), ... Model forecast, change
  from now to +72 h: T850 -1.9 K (NW -4.1, ...), Z500 -60 m.`
- 질문(리드마다 셋, 문턱은 2016 정답 분포에서 정해 질문 문장에 씁니다):
  - `drop_L`(예/아니오): 영역 평균 T850이 +L h에 지금보다 τ_L K 이상 낮아지는가. τ_L은 2016 사례의 20 %가 해당하도록.
  - `z500_L`(3단계): 영역 평균 Z500 변화가 2016 삼분위 아래 / 사이 / 위.
  - `coldest_L`(4지선다): T850 변화가 가장 작은(가장 많이 식는) 사분면.
- 정답: WB2 64×32 정답장에서 +L h 값과 발행 시각 값의 차이.
- 분할(stage 02의 전처리 지침): 2016(B) head와 기준선 학습, 2019(C) 보정, 2020(D) 시험. CPU 판독 비용 때문에 Laya는
  B의 4번째마다, C의 6번째마다, D의 2번째마다 발행 시각을 씁니다. 기준선도 같은 행으로 학습하고 채점합니다
  (로지스틱 하나는 2016 전체로도 학습해 자료량의 효과를 봅니다).
- 방법:
  - 기후값: 2016 클래스 빈도.
  - 예측을 쓰인 대로 읽기: 상태 문장의 예측 숫자에 질문의 문턱을 그대로 적용(확률 0/1).
  - 로지스틱(예측 숫자 하나): 질문에 해당하는 예측 숫자만.
  - 로지스틱(모든 숫자): 상태 문장의 모든 숫자(쓰인 대로 반올림)와 계절.
  - Laya zero-shot: vega-U 판독기(Qwen3.5-0.8B 기반) 그대로.
  - Laya + 보정: 2019로 질문마다 온도와 conformal 문턱, 자동/검토 경계를 맞춤(head 없음).
  - Laya head + 보정: 2016으로 질문마다 head를 `fit()`하고 2019로 보정. Laya는 교차검증 정확도가 판독기 자체보다
    높은 head만 자동 응답에 씁니다.
- 채점(2020): 정확도, Brier 점수(선택지 합)와 기후값 대비 기술 점수, 보정 오차(ECE), 3단계 질문의 RPS, Laya의 90 %
  집합 포함률과 크기, 자동 응답 비율과 그 정확도. 차이의 95 % 구간은 7일 묶음 bootstrap.
